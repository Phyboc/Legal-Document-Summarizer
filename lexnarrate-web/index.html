WHAT LEXNARRATE DOES / 05

Built for clarity you can trust.

Every feature is source-grounded: summaries map back to the document, and unverifiable claims are flagged rather than invented.

⚖️

Dual summaries

Lawyer Mode keeps the section-aware legal structure; Citizen Mode rewrites it in plain language.

🔗

Cite & Verify

An NLI model checks each claim against the source and marks it supported, unsupported, or contradicted.

🎯

Outcome preservation

The operative order is routed to its own judgement section so the holding — ALLOWED / DISMISSED — is never dropped.

🧩

Section routing

A rule + classifier splits facts, arguments, reasoning and judgement before summarizing each with its own budget.

🛡️

PII redaction

Aadhaar, PAN, phone and email patterns are detected and can be redacted before anything is summarized.

💬

Ask & search

Grounded Q&A answers only from the uploaded document, with full-text search and JSON / Markdown / text export.

HOW IT WORKS / 06

From a dense judgment to a clear explanation.

Six stages run on every document — the same pipeline the research was built and evaluated on.

01

Upload & extract

Drop a PDF, DOCX or TXT. Text is extracted and cleaned of court-PDF artefacts.

02

Clean & redact

Preamble is stripped and PII patterns are optionally redacted.

03

Detect sections

Paragraphs are labelled facts / arguments / reasoning / judgement, keeping the operative order intact.

04

Summarize

A fine-tuned BART model summarizes each chunk with a section-specific token budget.

05

Aggregate & format

Chunk summaries are merged and rendered as Lawyer Mode and plain-language Citizen Mode.

06

Cite & Verify

Each sentence is checked against the source; grounded extraction fills dates, parties, provisions and outcome.
